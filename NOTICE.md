# Aviso de uso

© 2026 Bruno Reis. Todos os direitos reservados.

Este repositório é publicado como **portfólio e cópia de leitura** — não é um template de código
aberto.

**Pode:** ler, estudar, executar localmente, e citar trechos com atribuição.

**Não pode:** reutilizar comercialmente as composições de página ou as identidades visuais, no
todo ou em parte. São os modelos de trabalho de uma prática real.

As marcas, textos, preços, depoimentos, CNPJs e registros profissionais das dez demonstrações são
**fictícios**. Qualquer semelhança com empresa existente é coincidência, e nenhuma das páginas
deve ser interpretada como representando um negócio real.

As fotografias vêm do Unsplash, sob a licença do Unsplash, e **não são redistribuídas** neste
repositório: são baixadas sob demanda por `npm run photos`.

Quer usar alguma coisa daqui? brunoereiss@gmail.com — a resposta costuma ser sim.
